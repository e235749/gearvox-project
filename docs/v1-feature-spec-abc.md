# GearVox v1.1 機能仕様書（A / B / C）

作成日: 2026-09-18  
対象ブランチ: `cursor/review-posting-flow`  
前提: Phase 1（本番デプロイ・認証・管理者・類似度バッチ）完了後の改善

---

## 1. 概要

公開 v1 の体験向上として、次の3領域を実装する。

| 領域 | 目的 |
|---|---|
| **A. ギアカテゴリ** | 公式カテゴリを整備し、検索・投稿の軸を増やす |
| **B. サイト速度** | ホーム／マイページ等の遷移・表示を軽くする |
| **C. 検索の二分化** | 商品検索と、ホームでのレビュー絞り込みを分ける |

---

## 2. A. ギアカテゴリ

### 2.1 方針

- v1 は **公式シードのみ**（ユーザーによるカテゴリ自由入力・申請はしない）
- 既存「テント」はそのまま残す
- 既存「ランプ」は **「ランプ・照明」にリネーム**
- 不足カテゴリを INSERT（同名は入れない）
- 階層（`parent_id`）は使わない

### 2.2 公式カテゴリ一覧（19）

1. テント  
2. ランプ・照明  
3. タープ  
4. シュラフ  
5. マット  
6. チェア  
7. テーブル  
8. 調理器具  
9. バーナー  
10. コンロ  
11. 焚き火・BBQ  
12. クーラー  
13. 食器・カトラリー  
14. バッグ・収納  
15. ウェア  
16. キャンプ用電源  
17. アウトドア家電  
18. ナイフ・工具  
19. その他  

### 2.3 実装

- マイグレーションでリネーム＋シード
- 既存のカテゴリ選択 UI（検索・ギア申請・管理）はそのまま利用

### 2.4 対象外（v1）

- カテゴリ管理 UI
- ユーザーによるカテゴリ申請

## 3. B. サイト速度

### 3.1 B1. フィード取得の軽量化

| 項目 | 仕様 |
|---|---|
| 一覧表示 | **タイトル ＋ 本文先頭40文字**（切れれば `…`） |
| 取得 | 一覧クエリでは本文全文を持たず、プレビュー用に短縮 |
| 詳細ページ | 本文全文（現状どおり） |
| 目的 | しっかり書いたレビューと軽い投稿の差を一覧でも示す |

対象: ホーム、ギア詳細レビュー一覧、マイページ／他ユーザーの投稿カード、簡単検索結果

### 3.2 B2. 表示件数

| 画面 | 初回 | 続き |
|---|---|---|
| ホーム（新着／フォロー中） | **20件** | 「もっと見る」で **+10件** 追加読み込み |
| ギア詳細のレビュー一覧 | **20件** | 「もっと見る」で **+10件** |
| マイページ／他ユーザー | **最新5件** | **「投稿一覧」** ボタン → 専用ページ |

投稿一覧ページ（新規）:

- `/profile/reviews`（自分）
- `/users/[id]/reviews`（他ユーザー）
- 一覧ページの件数はホーム同様 **20 → +10** とする

### 3.3 B3. 画像最適化

| 項目 | 仕様 |
|---|---|
| 方針 | **品質優先**（魅力を落とさない） |
| 一覧 | `next/image` ＋ 表示に十分な解像度（極端な縮小・強圧縮はしない） |
| 詳細 | 高品質を維持 |
| 設定 | Supabase Storage を `remotePatterns` に追加 |

### 3.4 対象外（本仕様の範囲外）

- B4 以降（検索の全面サーバー化、いいね集約 RPC 等）は必要に応じて別途
- コンテキスト条件でのレビュー検索（→ C の v1 以降）

## 4. C. 検索の二分化

### 4.1 定義

| 名称 | 意味 | 場所 |
|---|---|---|
| **詳細検索** | 商品（ギア）を探す | 既存 `/search` |
| **簡単検索** | ホームで条件により **表示レビューを制限** | ホーム上部 |

### 4.2 簡単検索（v1）

| 項目 | 仕様 |
|---|---|
| 条件 | **ギア属性のみ**（カテゴリ、ブランド） |
| 結果 | ホーム上のレビュー一覧を絞り込み表示 |
| 表示 | B1（タイトル＋本文40文字）、件数は B2 に準拠 |
| 類似度バッジ | 既存どおり表示 |

### 4.3 対象外（v1 以降）

- ユーザーコンテキスト（同行者・目的等）によるレビュー絞り込み

---

## 5. 実装順序

1. A（カテゴリシード）  
2. B1（本文プレビュー）  
3. B2（件数・投稿一覧ページ）  
4. B3（画像）  
5. C（ホーム簡単検索）
